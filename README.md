# БИХОН — насби барнома дар Android ва iPhone

Ин бастаи PWA аст: як сайти оддӣ, ки ба экрани асосии телефон ҳамчун барномаи пурра насб мешавад (бо иконкаи BIKHON, бе сатри браузер).

## 1. Ҷойгир кардани файлҳо дар интернет (як бор, ройгон)
Сайт бояд бо HTTPS дар ягон ҷо ҷойгир шавад. Осонтарин роҳҳо:
- **Netlify** (app.netlify.com/drop): папкаи `bikhon-pwa`-ро кашида монед, пайванд мегиред. Барои нигоҳ доштани он ба ҳисоби ройгон ворид шавед.
- **GitHub Pages**: репозитория созед, ҳамаи файлҳоро бор кунед, Settings → Pages → Branch: main.
- **Cloudflare Pages**: Direct Upload, папкаро бор кунед.
Ҳудуди андозаи як файл дар ҳар хидмат гуногун аст (масалан Cloudflare Pages тақрибан 25 МБ), пас барои PDF-и калон (Қуръон) аввал ҳудудро тафтиш кунед ва GitHub Pages ё Netlify-ро интихоб кунед.

## 2. Қуръон ва Ҳисн дар дохили барнома
Пеш аз боргузорӣ дар папкаи `books` файлҳоро бо номҳои **quran.pdf** ва **hisn.pdf** гузоред. Ҳангоми аввалин кушодани барнома онҳо худкор ба китобхона илова мешаванд (интернет лозим аст, танҳо як бор). Агар файлҳо набошанд, китобҳоро дастӣ бо тугмаи ＋ илова мекунед.

## 3. Насб дар телефон
- **Android (Chrome):** пайвандро кушоед → меню ⋮ → «Install app» / «Add to Home screen».
- **iPhone (дар Safari, на Chrome!):** пайвандро кушоед → тугмаи «Share» → «Add to Home Screen».
Баъд иконкаи БИХОН дар экрани асосӣ пайдо мешавад ва барнома дар экрани пурра кушода мешавад. Дустатон ҳамин пайвандро мекушояд ва ҳамин тавр насб мекунад.

## Эзоҳҳо
- Китобҳо ва ёддоштҳо дар ҳар телефон алоҳида нигоҳ дошта мешаванд (ҳамоҳангсозии аккаунт дар ин нусха нест). Нусхаи эҳтиётӣ: тугмаи PDF дар «Муҳиммот».
- Нусха барои Android APK: сайти pwabuilder.com. Дар App Store гузоштан ҳисоби Apple Developer ва Mac мехоҳад.
